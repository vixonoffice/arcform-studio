## Ce conține

- Portofoliu de proiecte și pagină de echipă
- Formular dedicat de cerere de ofertă
- Blog pentru SEO și buton fix de WhatsApp
- Hero full-screen cu imagine de arhitectură

## Stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · React Router · Framer Motion

## Rulare locală

```sh
npm install
npm run dev
```
